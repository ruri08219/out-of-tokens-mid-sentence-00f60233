## The entry

`main.py` writes one line to `/output/entry.txt` — the error message an
AI agent shows when it runs out of tokens mid-sentence:

> Error: token budget exhausted at word 47 of a 48-word sentence. The conclusion is now available as DLC.

The joke is the flat error tone turning on itself: the sentence dies one
word short of its ending, and the ending it was building toward is now
paywalled as DLC.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (103 characters, one line, UTF-8).
